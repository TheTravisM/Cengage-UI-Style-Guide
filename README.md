## Overview
A foundational design system and living documentation platform engineered for Cengage Learning. Built on a heavily customized Bootstrap framework utilizing LESS, this system standardizes responsive layouts, typography, and interactive UI components to enforce accessible, cohesive development across large-scale enterprise educational platforms.

## Architectural Mission
The primary objective of this project was to architect a scalable UI component library and establish a single source of truth (living documentation) for distributed teams. This infrastructure drives design consistency, reduces UI technical debt, and significantly streamlines front-end development workflows from prototyping to production.

## Core System Features
* **Living Documentation:** A centralized, interactive hub for developers and designers to view component states, copy standardized markup snippets, and review usage guidelines.
* **Customized Theming Engine:** Deeply overridden and extended Bootstrap variables via LESS to programmatically enforce Cengage's strict brand and styling guidelines.
* **Enterprise Accessibility:** Component architecture designed with foundational WCAG considerations, ensuring educational software compliance and usability.
* **Modular Architecture:** Decoupled CSS/LESS architecture ensuring UI components can be consumed and implemented independently without global layout pollution.

## Technology Stack
* **Languages:** HTML5, CSS3, JavaScript, jQuery
* **Preprocessors & Frameworks:** LESS, Bootstrap
* **Assets:** Font Awesome, responsive SVG/iconography
* **Design Methodology:** Mobile-First Architecture, Responsive Web Design (RWD)
